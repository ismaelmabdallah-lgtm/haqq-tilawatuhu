# Revision 2026-11-26 — from multi-tenant to free, public, unified

## What triggered it

New direction: free for everyone, no registration for learning or exams, no mosque management, one central admin team, zero mandatory hosting cost.

## Impact review of v1 (before changing code)

Tenancy ran through all four migrations: roughly 600 references to institutions, memberships, circles, invitations, `owner_institution_id`, `share_scope`, teacher-of-student checks, and institution-attested Ijazah records. Because **no migration had been applied to any real project yet**, v2 rewrites the four migrations in place instead of stacking a removal migration on top. The v1 files are kept in the previous delivery (haqq-tilawatuhu-foundation.zip).

## Removed

| Removed | Notes |
|---|---|
| institutions, memberships, invitations, create/invite/accept functions | mosques now just share the link |
| circles, circle members, attendance, student notes | |
| institution roles (owner/admin/supervisor/teacher/student) and their permission helpers | replaced by platform team roles |
| `owner_institution_id`, `share_scope`, institution-private content and its fast-publish shortcut | every public item is now scientifically reviewed |
| exam assignments to circles/students | exams are public |
| recitation submissions & teacher feedback | depended on teachers in circles; listed as a future feature |
| institution certificates (teacher assessment), Ijazah records/readings | certificates = level completion only; the platform never handles Ijazahs |
| Next.js skeleton (server-rendered pages + session middleware) | conflicted with the static, zero-cost design and could not be built here; About text kept in `docs/content/about.ar.md` |

## Added

* Guest exam attempts (hashed one-time token), resume, guest result access.
* Guest rate limiting (salted address hash, per-hour + global) and automatic purge of old guest attempts.
* `grader` role and a platform grading queue for manually marked parts.
* `requires_account` exams; level-final exams must require an account.
* Claiming guest attempts and importing browser progress after creating an account.
* Tajweed Academy tables: articulation points, letter characteristics, letters, their links and Quranic examples (all under review workflow).
* Files modelled by provider (`r2`, `supabase`, `youtube`, `external`) with a 25 MiB cap matching Cloudflare's per-file limit.
* `heartbeat()` for the free-tier keep-alive job; secret settings hidden from the API.

## Kept

Four levels and the curriculum seed (101 draft lessons with page references), lessons/resources/encyclopedia, scientific review state machine with snapshots and no self-approval, question bank with immutable versions, 11 part types with partial marks, automatic + manual grading, result/model-answer release rules, progress and mastery rules, certificates with strict Ijazah separation, announcements, audit log, Arabic search normalization.

## Tests

Database suite rewritten for the new model: **93 checks pass** (guest flows, rate limit, retention, account-only exams, claiming, review workflow, keys, certificates, storage, internal-function exposure). TypeScript: 10 unit tests pass, including SQL/TS normalization parity on the v2 schema.

## Not verified in this session

The Next.js application. Package installation is blocked in the environment used so far, so no frontend was built or tested. It is the first item of the next phase (see roadmap).
